How to Use

Secure, end-to-end encrypted messaging integrated directly into your GitHub experience. Get started in 3 simple steps.

Step 01

Visit a Profile

Open GitHub and visit any developer's profile page (for example, your own or a colleague's profile).

Step 02

Connect Account

Click the "Connect HitMeUp" button on the profile page to sign in and authorize the extension with your GitHub account.

Step 03

Send Request

Click "Send Request" on the user's profile to compose a secure message. You can view all incoming messages in your "Inbox".

Open GitHub
Zero-knowledge local encryption. Raw message contents are never visible to the server.
